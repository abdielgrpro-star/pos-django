# POS Django

Proyecto de práctica para aprender Django, Git y GitHub.

## Objetivo

Aprender la lógica de desarrollo de una aplicación web usando Django.

## Tecnologías usadas

- Python 3.14
- Django 6.0.6
- SQLite
- Git
- GitHub

## Funcionalidades planeadas

- Sistema de login
- Gestión de productos
- Gestión de ventas
- Reportes básicos
